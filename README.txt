# NextPath — OGAds landing page starter

## Files
- `index.html` — responsive English landing page
- `privacy.html` — starter privacy notice
- `disclaimer.html` — earnings/third-party disclaimer

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `NextPath` with your chosen brand name if desired.
3. Replace the two `https://example.com/...` placeholder links with the correct offer URLs from your OGAds dashboard.
4. Only add OGAds content-locker/embed code copied from your own dashboard, and follow OGAds' current integration instructions. Do not invent or modify tracking code.
5. Update the privacy notice if you add analytics, forms, cookies, or third-party scripts.
6. Test every link on desktop and mobile.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, for example `nextpath-landing`.
3. Upload `index.html`, `privacy.html`, and `disclaimer.html` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish. Your site URL will appear in the Pages section, usually like `https://YOUR-USERNAME.github.io/nextpath-landing/`.

GitHub's interface and free-plan terms can change. If Pages is not available for your repository/account, use another static host such as Cloudflare Pages or Netlify's free tier and follow its current upload/deploy instructions.

## Important
- Do not claim guaranteed earnings or misrepresent what an offer requires.
- Do not send unsolicited spam or use misleading buttons/pop-ups.
- Confirm that your traffic methods and landing page comply with OGAds' current publisher terms and the rules of each traffic platform.
- This starter project does not include an OGAds locker because the correct code is account-specific and must be copied from your OGAds dashboard.
